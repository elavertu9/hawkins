---
title: Demogorgon
spirit: Bourbon
summary: A maple old fashioned with an orange twist and a cherry, topped with a mini stroopwafel.
glass: Rocks glass
from: "The Upside Bar at Stranger Things: The Experience"
# image: /assets/images/cocktails/demogorgon.jpg
# image_alt: Amber old fashioned with a stroopwafel across the top
ingredients:
  - { qty: "2 oz", item: "bourbon, such as WhistlePig" }
  - { qty: "¼ oz", item: pure maple syrup, shop: maple syrup, shop_aisle: Baking }
  - { qty: "2 dashes", item: Angostura bitters }
  - { qty: "1", item: "strip of orange peel, for the twist", shop: orange }
  - { qty: "1", item: Luxardo maraschino cherry, shop_aisle: Drinks & Alcohol }
  - { qty: "1", item: mini stroopwafel, shop_aisle: Snacks }
steps:
  - Fill a cocktail shaker with ice and add the bourbon, maple syrup, and bitters.
  - Shake hard until the shaker is frosty, about **15 seconds**.
  - Strain into a rocks glass over one large ice cube.
  - Twist the orange peel over the drink to spritz its oils, then drop it in with the cherry.
  - Rest the stroopwafel across the top of the glass.
