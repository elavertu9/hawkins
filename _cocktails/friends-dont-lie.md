  - { qty: "1½ oz", item: blanco tequila }

  - { qty: "½ oz", item: grenadine }
  - { qty: "1 pinch", item: "edible glitter (optional)", shop_aisle: Baking }
  - { qty: "1", item: orange slice, shop: orange }
steps:
  - Stir the glitter into the grenadine, if you're using it.
  - Fill a tall glass with ice. Add the tequila and orange juice, then top with the soda.
  - Pour the grenadine slowly down the inside of the glass so it sinks to the bottom.
  - Garnish with the orange slice.
